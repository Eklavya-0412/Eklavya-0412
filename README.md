### CURA_SENSE 🔗

> An automated Agentic AI Site Reliability Engineering (SRE) platform designed for root-cause analysis and automated self-healing during complex migrations.

CURA_SENSE acts as an intelligent SRE, monitoring system health and autonomously resolving infrastructure anomalies before they result in downtime.

#### Core Features

- **Agentic Orchestration**
  Utilizes an ORDA reasoning loop to autonomously investigate, diagnose, and execute resolutions for system failures.

### AI-Proctor 🔗

> An automated, highly scalable code execution and proctoring platform with a real-time code editor and a secure, isolated sandbox environment.

The backend follows a strict layered architecture, keeping data mutation predictable and business logic clean.

#### Core Features

- **Isolated Code Execution**
  A Go-based execution engine runs submitted code inside secure, ephemeral Docker containers, handling timeouts and memory limits while blocking malicious payloads.

- **Strict Layered Architecture**
  A decoupled backend flow — `Routes → Controllers → DTOs → Services → Problem Schemas` — for predictable data handling and modular debugging.

- **Real-Time Editor**
  A live coding interface built for continuous proctoring and immediate sandbox feedback.

#### Tech Stack

`Go` `React` `Docker` `MongoDB`
